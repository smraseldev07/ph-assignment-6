# FITLOG

FITLOG is a modern workout tracking web application that helps users explore exercises, create a personalized workout plan, save exercises for later, and track their workout progress.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Context API
- Next.js Image
- REST API
- React Hot Toast

## ✨ Key Features

### 1. 🏋️ Workout Library
Browse a collection of exercises with useful information such as:
- Muscle groups
- Equipment
- Difficulty
- Duration
- Calories burned
- Rating
- Sets and reps

### 2. 📋 Personalized Workout Plan
Add exercises to your **Today's Plan** and manage your workout routine from one place.

### 3. 💾 Save Exercises
Save workouts for later and access them from the **Saved** section.

### 4. 🔍 Workout Details
View detailed information about each exercise, including descriptions, instructions, equipment, sets, reps, duration, and calories.

### 5. ✅ Workout Progress Tracking
Mark exercises as completed, remove exercises from your plan, and view updated workout statistics such as total exercises, minutes, and calories.
